FLEETPRO WEBSITES

Websites redesign and brand identity materials for two branches of american logistics company: FleetPro Warehousing & FleetPro Truck Center

My contribution:
  • Responsive design
  • UI Kit, reusable components
  • Color palette & typography
  • Brandbook & advertisement
Tools I used:

Starting Point

The challenge:

  • Unsystematic UI
  • Duplicates & inconsistent UI across pages
  • Difficult scaling
  • No possibility to add pages in same styles
  • Hard for developers to work with it

My approach:

  • Refined, rather than redesigned the visual style
  • Standardized core UI elements
  • Created reusable components
  • Made it ready-to-dev

UI-Kit

Components

Rebuilt core UI elements as reusable components, making the interface easier to maintain and extend.

Typography

Structured existing typography styles and standardized text styles across the websites.

COLOR SYSTEM

Organized the existing brand colors into a consistent, reusable color system.

New pages

As the businesses expanded, new services required new pages. The redesigned UI made it easy to add new content while staying consistent with the existing design.

Brandbook

While working on the websites, I also created a brandbook to document and standardize the visual identity across both companies.

Outcome

A consistent and scalable UI foundation with reusable components, easier implementation, and flexibility for future pages.
