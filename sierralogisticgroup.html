SIERRA LOGISTICS GROUP

Website and brand identity for american logistics company

My role:
  • UI/UX design
  • Web design
  • Visual identity
  • Front-end implementation
Tools I used:

Starting Point

The initial brief was open-ended: the client needed a website but had no defined visual direction, structure or specific UX requirements. They provided a reference website that matched the general style they liked and left the rest open for interpretation.

Client provided:

  • Company name
  • Logo
  • Reference website
  • General business information

I defined:

  • Visual direction
  • Brand system
  • Website structure
  • UI & Responsive behavior
  • Implementation

Brand identity development

While the website was still undefined, I started by establishing a visual system around the existing logo. I first applied the identity to business cards and then developed a brandbook with the core visual styles.

From concept to live website

With no predefined UI or wireframes, I developed the website iteratively using AI-assisted coding. I explored the visual direction directly in the browser, refining the layout and styling in VS Code until the final result was achieved. The website was then deployed via GitHub and delivered to the client.
